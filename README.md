# Social Link-Sharing Profile

A small, responsive profile page that shares my existing public profiles in one place: GitHub, LinkedIn and Facebook. It is also a test run of the Bootstrap library.

## Languages and tools

- **HTML**: page structure and semantic markup
- **CSS**: custom theme colours, card sizing, and hover and focus states
- **Bootstrap 5.3**: layout utilities and button styling, loaded from the jsDelivr CDN

## Features

- Responsive layout for mobile and desktop
- Hover and focus states on every link
- Keyboard-friendly navigation with visible focus outlines
- Profile picture pulled from my GitHub account
